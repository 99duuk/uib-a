## 3. 비교만

### 기본 배치

```text
프로젝트 이름                    [비교만] [간편 수정] [상세 검토]
[서재 · 기본 · 모바일 ▾]

┌────────── BEFORE ──────────┐  ┌────────── AFTER ───────────┐
│                           │  │                            │
│          전 화면          │  │          후 화면           │
│                           │  │                            │
└───────────────────────────┘  └────────────────────────────┘
```

- 상시 요소: 프로젝트명·모드 전환·통합 화면 선택·Before/After 제목·비교 화면
- 통합 화면 목록: 실제 entry별 항목, 화면명·기기 표시 및 구분에 필요한 상태·시안 표시
- 단일 entry의 화면 선택: 조작 불필요한 현재 화면명 표시로 대체
- 데스크톱 기준: 768px 이상에서 Before/After 나란히 기본값·가용 폭에 맞춘 축소
- 모바일 기준: 768px 미만에서 Before/After 탭·After 첫 표시·두 탭의 상시 노출
- 캡처 구간: 여러 타일 존재 시 해당 패널의 구간 선택만 조건부 노출
- 원본 미확보: Before 패널 내 `원본 미확보` 표기·비교 완료 오인 방지
- 수정 결과 포함 화면: After 제목의 `수정 반영` 소형 표시
- 미저장 변경 존재 시 예외: 상단 `미저장 변경 · 저장` 표시
- 숨김 대상: 좌측 목록 패널·우측 편집 패널·검토 진행 수치·요소 목록·삭제 버튼·판정·개발용 정보·설명 펼치기
- 입력 동작: 스크롤·화면 이동만 허용, 요소 선택·드래그 지정·편집 단축키 차단

## 4. 간편 수정

- 진입 안내: `화면에서 바꿀 부분을 선택하세요` 한 줄
- 첫 상태: 비교 화면 유지·빈 편집 패널의 상시 점유 제거
- 선택 방법: 화면 클릭·터치·키보드, 보조 `요소 찾기` 목록
- 선택 결과: 선택 테두리·짧은 대상 이름·선택한 측 표시
- 데스크톱 편집 패널: 선택 후 우측 표시·닫기 후 캔버스 복귀
- 모바일 편집 패널: 선택 후 하단 시트·닫기 버튼·배경과 구분되는 표시
- 편집 작업: `임시 삭제`, `문구 수정`, `글자색`, `글자 크기`, `수정 요청`
- 편집값 초기화: 선택 대상의 현재 적용값 표시·직접 적용 버튼을 통한 확정
- 문구 수정 가능 대상: 작성형 After의 하위 의미 요소 없는 텍스트
- 글자색·크기 수정 가능 대상: 작성형 After의 기존 허용 patch 대상
- Before·캡처형 After: 이미지 직접 편집 대신 임시 가리기·수정 요청 제공
- 불가 기능: 해당 편집 입력 숨김·`이미지 캡처 — 직접 수정 대신 요청 작성` 짧은 안내
- 수정 요청: 기존 의견 저장 구조 사용·기본 우선도 P2·우선도/작성자 설정 숨김
- 기존 상세 의견: 텍스트와 상태 요약 표시·세부 수정의 상세 검토 연결
- 변경 이력: 삭제·시안 변경의 소형 요약과 개별 복원, 펼치기 전 긴 목록 숨김
- 저장: 상단 단일 `검토 파일 저장` 버튼·중복 저장 버튼 제거
- 되돌리기·다시 실행: 편집 단계 공통 도구·가능한 작업 부재 시 비활성
- 제외: 자유 배치·드래그 리사이즈·임의 CSS·코드 편집·서버 반영

## 5. 상세 검토의 정리

- 진입 상태: 비교 화면 중심·도구 그룹 기본 접힘
- 기존 `모드` 셀렉트 명칭: `선택 방식`으로 변경·상단 3단계 모드와 혼동 방지
- 상시 도구: 화면 이동·요소 선택·되돌리기·다시 실행·저장·검토 도구 열기
- 선택 방식: 기본 `요소 선택`, 추가 `다중 선택·영역 의견·영역 요소·텍스트 의견·이동·로컬 체험`

| 그룹 | 내용 | 노출 조건 |
| --- | --- | --- |
| 비교 설정 | 나란히/한쪽/슬라이더/겹침/픽셀 차이·배율·핀·모션·동기 스크롤·원본/수정본 | 사용자가 펼친 상태 |
| 요소 정보·시안 수정 | 요소 목록·부모 경로·복사 정보·허용 스타일·토큰·내장 이미지 | 요소 선택 + 그룹 펼침 |
| 의견 | 작성자·우선도·의견·답글·해결·재연결 | 대상 선택 + 의견 그룹 펼침 |
| 검토 판정 | 현재 화면 판정·사유·일괄 판정 | 사용자 펼침, 일괄 판정의 기존 확인 절차 유지 |
| 파일 및 인계 | 저장 JSON·가져오기·충돌·미해결 연결·Markdown/JSON 인계·PNG·요소 목록 | 사용자가 펼친 상태 |
| 디자인 근거 | 브랜드·근거·검토 범위 | 사용자가 펼친 상태 |

- 긴 JSON·소스 메타데이터: 기본 숨김·복사/펼치기 후 열람
- 의견 카드: 본문·상태·주요 작업 우선, 편집 textarea·답글·재연결의 상시 전개 제거
- 선택 완료·취소: 다중/영역 선택 진행 중에만 표시
- 원본/수정본 전환: 실제 삭제·시안 변경 존재 시 노출
- 가져오기 후 충돌·미해결: 해당 그룹 제목의 건수 표시·기존 사용자 선택 후 적용 계약 유지
- 제품 화면의 CLI 명령 안내: 제거·사용 문서로 이동
- 기능 자체 폐기 대상: 없음; 중복 버튼·상시 노출·구현용 설명의 축소

## 7. 접근성과 시각 기준

- 모드 전환: 3개 이름의 항상 보이는 버튼·현재 모드의 색상 및 상태 속성 표시

- 터치: 주요 조작 영역 최소 44px·320px 화면 가로 넘침 없음
- 선택 정보: 긴 ID와 전체 복사 텍스트의 간편 단계 노출 제외
- 셀렉트 화살표: 기존 interaction 수정 유지·글자와 화살표의 겹침 방지
- 상태 구분: 보기 모드·선택 방식·현재 Before/After의 서로 다른 명칭
