# 데모 After 변경 근거

- 대상: 가상 독서 앱 Morrow, 프로젝트 관리 화면 Fieldwork
- 샘플 데이터: 기존 Before fixture 유지
- Before: 최초 공개 데모의 이미지·영역 맵·revision 보존
- After: Morrow `r2`, Fieldwork `r3`
- 고객 시안 설계 시 예시의 스타일·배치를 기본값으로 재사용하지 않음

## Morrow · 모바일 서재

- 사용자 행동: 읽던 책을 찾아 기존 위치에서 이어 읽기
- 유지 정보: 책 제목 2개, 128 / 240쪽, 읽는 책 1권·읽은 책 7권, 하단 메뉴
- 유지 색상: Before의 녹색 `#387159`
- 변경: 238px 장식 표지 영역 → 제목·진행 위치 옆 작은 표지
- 변경: 바깥 카드 제거, 읽기 버튼을 책 정보 바로 아래 배치
- 제거: 영문 장식 제목, 응원 문구, 원본에 없는 설명, 기울어진 표지 효과
- 확인창: 대상 책·시작 페이지·실행·돌아가기만 표시
- 표지: 예시 제목을 이용한 자체 제작 placeholder; 실제 출판물 표지 아님

## Fieldwork · PC 및 모바일

- 사용자 행동: 프로젝트 목록에서 검토 대상을 확인하고 표지를 보며 의견 작성
- 유지 정보: 프로젝트 3개, 담당자·상태·기한, 진행 중 12·검토 대기 4·이번 주 완료 8, 표지 시안 검토
- 유지 색상: Before의 청회색 `#345563`
- 사용자 피드백: r2의 간결한 구성도 흔한 생성형 대시보드 형태라는 지적
- 변경: 개요·숫자·배너·표 구성 → 프로젝트 목록 / 선택 문서 / 검토 요청
- 목록: 프로젝트 3개의 담당자·상태·기한 유지, 브랜드 가이드 선택 상태
- 통계: 목록 하단의 접을 수 있는 전체 현황으로 이동
- 문서: 원본에서 언급된 표지 시안을 자체 제작 예시로 구체화; 실제 업로드 파일 아님
- 검토: 문서와 요청을 함께 표시, 체험 모드에서 로컬 메모 입력
- 메모 제한: 제출·서버 저장·HTML 저장 시 입력값 보존 미지원; 요소 삭제 상태 저장과 별개
- 모바일: 목록 → 선택 프로젝트 → 표지 → 검토 요청 순서, 담당자·상태·기한 유지
- 제거: 가상 전역 메뉴, 상단 KPI, 확인 안내 배너, 넓게 늘린 3행 표
- 추가 데이터: 예시 표지 그래픽과 로컬 메모 입력 제안; 기존 프로젝트 수치·인물·기한 변경 없음
