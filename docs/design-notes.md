# 데모 After 변경 근거

- 대상: 가상 독서 앱 Morrow, 프로젝트 관리 화면 Fieldwork
- 샘플 데이터: 기존 Before fixture 유지
- Before: 최초 공개 데모의 이미지·영역 맵·revision 보존
- After: `r2`

## Morrow · 모바일 서재

- 사용자 행동: 읽던 책을 찾아 기존 위치에서 이어 읽기
- 유지 정보: 책 제목 2개, 128 / 240쪽, 읽는 책 1권·읽은 책 7권, 하단 메뉴
- 유지 색상: Before의 녹색 `#387159`
- 변경: 238px 장식 표지 영역 → 제목·진행 위치 옆 작은 표지
- 변경: 바깥 카드 제거, 읽기 버튼을 책 정보 바로 아래 배치
- 제거: 영문 장식 제목, 응원 문구, 원본에 없는 설명, 기울어진 표지 효과
- 확인창: 대상 책·시작 페이지·실행·돌아가기만 표시
- 표지: 예시 제목을 이용한 자체 제작 placeholder; 실제 출판물 표지 아님

## Fieldwork · PC 및 모바일

- 사용자 행동: 검토할 프로젝트 확인, 담당자·상태·기한 비교
- 유지 정보: 프로젝트 3개, 담당자·상태·기한, 진행 중 12·검토 대기 4·이번 주 완료 8, 표지 시안 검토
- 유지 색상: Before의 청회색 `#345563`
- 변경: 3개 통계 카드 → 한 줄 요약
- 변경: 오른쪽 안내 카드 → 표 위의 구체적인 검토 동작
- 변경: 프로젝트 속성의 열 정렬과 상태 점·텍스트 표시
- 모바일: 항목명·상태·담당자·기한을 유지한 행 목록
- 제거: 장식 영문 소제목, 임의 유니코드 아이콘, 반복 안내, 가짜 활동·추세 그래프
- 프로젝트 3개만 제공된 샘플의 여백 유지; 채우기용 데이터 추가 없음
