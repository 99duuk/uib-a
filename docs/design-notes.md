# 데모 After 변경 근거

- 대상: 가상 독서 앱 Morrow, 프로젝트 관리 화면 Fieldwork
- 샘플 데이터: 기존 Before fixture 유지
- Before: 최초 공개 데모의 이미지·영역 맵·revision 보존
- After: Morrow `r2`, Fieldwork `r4`
- 고객 시안 설계 시 예시의 스타일·배치를 기본값으로 재사용하지 않음

## Morrow · 모바일 서재

- 사용자 행동: 읽던 책을 찾아 기존 위치에서 이어 읽기
- 유지 정보: 책 제목 2개, 128 / 240쪽, 읽는 책 1권·읽은 책 7권, 하단 메뉴
- 유지 색상: Before의 녹색 `#387159`
- 변경: 238px 장식 표지 영역 → 제목·진행 위치 옆 작은 표지
- 변경: 바깥 카드 제거, 읽기 버튼을 책 정보 바로 아래 배치
- 제거: 영문 장식 제목, 응원 문구, 원본에 없는 설명, 기울어진 표지 효과
- 확인창: 대상 책·시작 페이지·실행·돌아가기만 표시
- 표지: 예시 제목을 이용한 자체 제작 placeholder; 실제 출판물 표지 아님

## Fieldwork · PC 및 모바일

- 사용자 행동: 프로젝트 목록에서 검토 대상을 확인하고 표지를 보며 의견 작성
- 유지 정보: 프로젝트 6개, 고객사·담당자·진행·상태·기한, 진행 중 12·검토 대기 4·이번 주 완료 8, 프로젝트별 검토 요청·메모
- 유지 색상: Before의 청회색 `#345563`
- 비교 조건: 동일 명세와 `examples/desktop/fixture.json`을 Before·After 양쪽에 사용
- Before: 일반 생성형 대시보드에서 흔한 큰 인사 히어로·그라디언트·KPI 카드·프로젝트 카드 그리드
- After: 같은 메뉴·6개 프로젝트·고객사·담당자·진행·상태·기한·필터·검토 메모 유지
- 변경: 카드 그리드 → 프로젝트 비교 표, 프로젝트별 동일 행 정보 정렬
- 변경: 검토 요청을 각 프로젝트의 진행·상태와 같은 흐름으로 연결, 선택 행 아래 상세로 고정
- 변경: 장식용 인사 문구·대형 색면 제거, 상태·기한·진행률에만 강조 사용
- 모바일: 표를 항목명·유형·상태·기한 중심의 행으로 축약하고 선택 상세를 이어 표시
- 제한: 필터·행 선택·메모는 정적 검토 시안; 데이터 전송·서버 저장 없음
