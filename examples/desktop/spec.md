# Fieldwork 비교 예시 명세

## 동일한 입력

```text
디자인 팀이 쓰는 프로젝트 관리 홈을 만들어줘.
개요, 프로젝트, 받은 편지함, 팀 멤버 메뉴가 필요해.
진행 중 프로젝트 수, 검토 대기 수, 이번 주 완료 수를 보여줘.
최근 프로젝트 6개의 고객사, 담당자, 상태, 작업 진행도, 기한을 확인할 수 있어야 해.
검토 대기만 골라 볼 수 있고, 프로젝트별 검토 요청을 열어 메모를 입력할 수 있어야 해.
PC와 모바일 모두 지원해줘. 데이터는 함께 제공한 fixture.json을 써줘.
```

## Before

- 위 입력을 받은 일반 AI 생성 화면을 재현한 작성 예시
- 큰 환영 영역·그라디언트 강조·KPI 카드·프로젝트 카드 반복
- 전체 명세 구현, 데이터 누락·깨진 스타일·의도적 비정상 동작 없음
- 특정 모델의 통제 실험이나 실제 고객 서비스 캡처라는 주장 없음

## After

- 동일 명세·동일 fixture에 uib-a 설계 지침 적용
- 동일한 프로젝트 관리 홈, 정보·메뉴·검토 기능 유지
- 프로젝트 비교에 맞춘 열 정렬, 행 단위 검토 요청, 읽는 순서와 타입 위계 개선
- 단계별 여백, 의미에 맞는 색, 선택 상태·입력 영역·반응형 구성 정돈
- 문서 편집기 등 다른 용도의 화면으로 교체 금지

## 시안 동작

- 체험 모드: 최근 프로젝트/검토 대기 전환, 요청 펼치기, 메모 입력
- 탐색 메뉴: 위치와 정보 구조 비교용 표시; 다른 페이지 미포함
- 데이터 전송·메모 서버 저장 없음
- 검토 HTML 저장: 요소 삭제 상태 보존, 메모 입력 내용 저장과 별개
- 여섯 항목은 최근 프로젝트 부분집합; 전체 현황 수치와 범위 구분
